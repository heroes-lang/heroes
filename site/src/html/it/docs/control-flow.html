Il flusso di controllo

Scegli con if, ripeti con for o while.

Il flusso di controllo è l’ordine in cui vengono eseguite le istruzioni. Heroes offre if per scegliere quali eseguire, for per percorrere una sequenza e while per ripetere un blocco finché una condizione è vera.

if, e solo bool

Una condizione deve avere tipo bool, quindi valere true o false. Numeri e stringhe non vengono convertiti automaticamente in condizioni: 

$ heroes check loops.hero
error[not_bool]: an `if` condition must be `bool`, found `i64` — there is no truthiness in this language
  at loops.hero:13:12
     |
  13 |         if x
     |            ^

Usa if, else if ed else per definire i rami. La condizione non richiede parentesi; il rientro delimita il corpo. if è anche un’espressione, cioè può produrre un valore. Puoi quindi usarlo per scegliere un valore senza assegnarlo separatamente nei due rami.

for x in xs: percorrere una sequenza

Il ciclo visita un elemento alla volta. A ogni iterazione la variabile contiene una nuova copia dell’elemento, senza un indice o un contatore da aggiornare.

Il prossimo capitolo spiega il simbolo @. Qui best: i64 @ floor dichiara una variabile modificabile e best @ x le assegna un nuovo valore. Un nome definito con = non può essere riassegnato.

Uscire prima: break

Saltarne uno: continue

break termina il ciclo più interno; continue passa alla sua iterazione successiva. Non puoi indicare un ciclo esterno con un’etichetta. Se devi uscire da più cicli, puoi spostarli in una funzione e usare return per terminarla.

while: ripetere su una condizione

Un while controlla la condizione prima di ogni iterazione. L’eventuale aggiornamento del contatore si scrive nel corpo, nell’ordine in cui deve essere eseguito.

Contare: un intervallo è una chiamata di funzione

range restituisce una lista di numeri: include from ed esclude to. Devi nominare entrambi gli argomenti perché hanno lo stesso tipo, i64, come spiegato nel capitolo 2.

Usa _ come variabile del ciclo quando non ti serve il valore dell’elemento. Come in un match, _ scarta il valore senza dichiarare un nome. Non può quindi produrre un errore per un nome inutilizzato.

Aggiungere testo a una stringa dentro un ciclo copia ogni volta l’intera stringa, con un costo che cresce a ogni iterazione. Per stringhe lunghe usa repeat o join, che costruiscono il risultato in una sola passata. Il capitolo sulle stringhe spiega la differenza.
