Cinque corpi sotto gravità per mille passi, e le due energie che un file pubblicato dice debbano avere.

Le condizioni iniziali sono copiate cifra per cifra dal programma C di riferimento, scritte senza esponenti perché questo linguaggio non li ha. È il primo programma qui il cui lavoro è impossibile senza il C: non può fare un passo senza una radice quadrata.
