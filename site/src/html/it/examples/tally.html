Un programma che conta righe, parole e byte ricevuti dallo standard input.

Lo standard input è il canale da cui un programma legge i dati che gli vengono passati. Il comando mostrato qui vi invia il contenuto di un file tramite una redirezione. Una funzione C legge i dati un byte alla volta. L’esempio accetta testo ASCII, un insieme limitato di caratteri che non comprende le lettere accentate.
