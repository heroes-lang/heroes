Un servizio di pubblicazione per più utenti, un piccolo server di blog e note scritto con il framework web di Rebel.

Le persone si registrano, entrano, scrivono note in Markdown con etichette, commentano le note degli altri e le cercano. Le pagine del sito e un’API JSON, la porta che usano i programmi invece dei browser, con un token al posto dell’accesso, servono le stesse note; un WebSocket, una connessione che resta aperta, avvisa l’autore di un nuovo commento mentre viene scritto; e un feed Atom porta le note più recenti a un lettore di feed. Le pagine sono in inglese o in italiano, con le date scritte come le scrive ciascuna lingua.

L’output di questa pagina è la sua demo: il server avviato sulla macchina stessa con un database SQLite nuovo e un orologio fisso, guidato dal suo stesso client su un secondo thread, poi fermato attraverso la sua API e la sua cartella rimossa, con un resoconto uguale a ogni esecuzione. Il pacchetto web di Rebel instrada le richieste e porta con sé sessioni, protezione dai moduli contraffatti e limiti di frequenza, template genera le pagine, markdown e html/sanitize trasformano le note in HTML sicuro, sql/sqlite e sql/migrate conservano i dati, search ordina i risultati di una ricerca e openapi descrive e controlla l’API.
