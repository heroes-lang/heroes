Ready-made functions for text and numbers that a program copies into its own folder, and the program that runs their tests.

A core package is Heroes source code that a program copies, unchanged, into its own core/ folder and brings in with a line such as use core/strings. The language ships no standard library, the set of ready-made functions many languages install with their compiler, so a package is ordinary Heroes code, checked the way any program is: by the compiler and by its own tests. This program uses every package, so heroes test on it runs their tests as well as its own, and when it runs it prints what a few calls answer.

The program does not read the files listed as input. README.md holds the rules every package follows, and each card, such as core/strings.md, lists a package’s functions beside the call a program writes for each one.
