Ready-made functions for text and numbers that a program fetches into its own folder, and the program that runs their tests.

A core package is Heroes source code that a program fetches into its own folder with heroes add core and brings in with a line such as use <core>/strings, where the name in angle brackets is the entry of the program’s catalogue that says where the package comes from. The language ships no standard library, the set of ready-made functions many languages install with their compiler, so a package is ordinary Heroes code, checked the way any program is: by the compiler and by its own tests. This program uses every package, so heroes test on it runs their tests as well as its own, and when it runs it prints what a few calls answer.

Beside the program, its folder holds README.md, the rules every package follows, which the program does not read. The packages are published in another folder of the repository, the index every example’s catalogue reads, and each package has a card, such as strings.md, which lists its functions beside the call a program writes for each one.
