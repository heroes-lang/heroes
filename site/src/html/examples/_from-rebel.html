Every code block on this page comes from a file in examples-rebel/ and is generated when the site is built. The recorded output below the command is compared with the program’s output byte for byte, on Linux, macOS and Windows, by the check of Rebel’s programs, each time Rebel or these programs change; a program that rewrites one of examples/ with Rebel is held to that program’s output. Where a line depends on the machine, a file beside the program names that line and its other forms, or the platform where the program cannot run.
