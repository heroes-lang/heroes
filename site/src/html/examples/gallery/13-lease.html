Hand a C library text it will keep, and say when you are done with it.

A string lent with .cstr() is C’s to read for one call, and some libraries keep the pointer and read it later. The header cannot say which, so the program does: x: cstr @ s.lease() hands C a copy of the bytes that lives until end_lease(@x) frees it and empties the cell. The name of a lease may stand only as an argument of a call and nothing else writes its cell, which is what makes a second release impossible. A lease nobody ends is named when the program exits. The C side here is the smallest library that keeps what it is given, in a header beside the file.
