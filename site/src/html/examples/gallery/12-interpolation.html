Put a value inside a string, and let the compiler say when it has no text.

An f before the opening quote lets a string carry values: f"{at}/{of} {star.name}" writes each hole as to_str would write it. Any expression may stand in a hole, including a call or another string of the same kind; {{ writes one opening brace, and outside a hole a closing brace is not special. A hole may hold what to_str can render: an integer, a float, bool or str. A record, an array or a value that may be missing is refused at the hole, and the note says what to write instead.
