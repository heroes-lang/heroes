Read a JSON document, describe its structure and print it in a consistent format.

The reading and the writing come from encoding/json, one of the core packages, which hands back the document as one value of six kinds: nothing, true or false, a number, a string, an array or an object. Arrays and objects hold further values of the same type, so documents nest. What the program writes itself is its own question about the document, how many values it holds and how deep they go, answered by visiting each value and choosing what to do by its kind.
