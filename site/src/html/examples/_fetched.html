This program uses a package, code published to be shared between programs, so it has a catalogue: heroes.toml, beside its main.hero, names Rebel as one entry, rebel, read from the repository’s own folder by its path, and its packages line lists the packages of Rebel the program uses, a use of any other being refused. Its build compiles those packages and the modules they use, nothing else of Rebel. A program that took Rebel from an index would hold its exact version and its fingerprint as well, a number computed from every byte of every file, and a copy of the packages it lists under heroes.packages/, which the compiler checks against the fingerprint every time it builds; the chapter on packages shows both.
