This program uses a package, code published to be shared between programs, so it holds a catalogue: heroes.toml names the core packages as one entry, core, with the exact version and the fingerprint (a number computed from every byte of every file, so it changes if a single byte does) that the index, the folder where the packages are published, gives for that version. heroes add core wrote the catalogue and copied that version’s files into the program’s folder, under heroes.packages/. They are the package’s code and not the program’s own: the compiler checks them against the fingerprint every time it builds, and never downloads anything while it does.
