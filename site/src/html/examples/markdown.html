Convert Markdown to plain text, with the work split across modules.

Each module written for this program is a file with its own job: read formatting within a line, recognise blocks such as paragraphs, assemble the page, or run the program. The functions that split the text into lines, trim them and check how each one begins come from the <core>/strings package, ready-made code the program fetched into its own folder with heroes add. A match branch uses continue to skip to the next loop iteration.
