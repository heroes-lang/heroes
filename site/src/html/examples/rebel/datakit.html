A data tool for the terminal, in the family of xsv, jq, Miller and a small pandas: many formats in, one table model, queries, SQL and reports out.

It reads tables and documents in CSV, TSV, XLSX, JSON, JSON Lines, YAML, TOML, INI, Java properties, XML, MessagePack, CBOR and BSON into one model, whose numbers are exact decimals and whose dates stay dates, and converts between them. It selects with JSONPath, filters, groups and aggregates with an expression language of its own, runs SQL over files loaded into SQLite, shows a table in a scrollable full-screen view, and writes a PDF report.

The output on this page is its demo: sample files written, a long series of commands run over them, what they wrote read back, and the folder removed. Rebel gives each format its package, from csv and xlsx to bson; big keeps the decimals exact, stats computes deviations and percentiles, sql/sqlite runs the SQL, tui draws the view, and pdf writes the report. Java properties have no package in Rebel and are read and written by the program itself.
