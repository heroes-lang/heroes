The small web server, written again with Rebel’s http, net and threads, each connection still served on a thread of its own.

Rebel’s http reads each request by RFC 9112, the standard for HTTP/1.1 messages, within fixed limits, answers 400 to what is not a request and writes each response; its net listens, accepts and connects; its threads starts each thread and waits for it. Together they replace the original’s own http.hero and net.hero and its direct calls to the runtime’s thread functions.

The loop that gives each connection its own thread stays this program’s: Rebel’s http.serve serves one connection at a time and leaves that loop to the program. A connection crosses into its thread as a number and is taken back with it there, since a Heroes thread is handed one number and nothing else. Run with no words it plays both sides in one process and prints the same thing on every run; run as serve 8080 it waits for connections on that port from the machine itself.
