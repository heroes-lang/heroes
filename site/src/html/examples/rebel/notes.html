A multi-user publishing service, a small blog and notes server written on Rebel’s web framework.

People register, sign in, write notes in Markdown with tags, comment on each other’s notes and search them. The site’s pages and a JSON API, the door programs use rather than browsers, with tokens in place of a login, serve the same notes; a WebSocket, a connection that stays open, tells an author of a new comment as it is written; and an Atom feed carries the newest notes to a feed reader. The pages come in English or Italian, with dates written as each language writes them.

The output on this page is its demo: the server started on the machine itself with a fresh SQLite database and a fixed clock, driven by its own client on a second thread, then stopped through its API and its folder removed, printing a transcript that is the same on every run. Rebel’s web routes the requests and brings sessions, protection against forged forms and rate limits, template renders the pages, markdown and html/sanitize turn notes into safe HTML, sql/sqlite and sql/migrate keep the data, search ranks the results of a search, and openapi describes and checks the API.
