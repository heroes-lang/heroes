Words counted on threads, written again with Rebel’s threads, which starts the threads and collects what each counted.

Rebel’s threads starts one thread for each band of text, waits for every one and gives back their counts in order, in place of the original’s own calls to the runtime’s thread functions and its list of threads to wait for. Its strings cuts the text into words, its maps counts each word, and its math adds the counts, answering an error rather than stopping the program if the sum does not fit. Each thread still builds the text it reads from the one number it is given, so nothing is shared and only a number comes back.
