An API gateway in the manner of Envoy and Kong, in small: one front door that routes, caches, limits and translates requests for the services behind it.

It accepts clients over TLS, the encryption HTTPS uses, speaking HTTP/1.1 or HTTP/2, routes each request by its host and path, and finds the service behind the route through DNS records. It forwards plain HTTP through a cache, relays gRPC calls, turns a plain request into a gRPC call answered as JSON, and answers GraphQL from one schema built from two services, gRPC and GraphQL being two common ways services call each other. Every client has a rate limit per route, a failed call is tried on the next instance, an instance that keeps failing is skipped for a while, and the gateway serves its own metrics for Prometheus.

The output on this page is its demo, fed the routing file shown under Input: a DNS server and three services the program carries, a catalogue over HTTP, an inventory over gRPC and reviews over GraphQL, started on the machine itself, the gateway served in front of them, and a scripted client speaking to it over TLS. Rebel’s tls, http and http2 carry the traffic, grpc and protobuf relay and translate, graphql composes the schema, dns finds the services, retries tries again, and metrics counts.
