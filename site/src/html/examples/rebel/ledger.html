The SQLite ledger, written again with Rebel’s sql/sqlite in place of its own bindings, every total still checked twice.

Rebel’s sql/sqlite opens the database in memory, runs statements with their values bound to placeholders, prepares a statement once to run it many times, and answers a query’s rows. It replaces the original’s own binding of SQLite’s C interface, with its handles and its care that every statement is released and every error message freed on every path. Rebel’s sql reads a row’s values by their type, refusing a text read as a number rather than answering zero, and strings pads the report’s columns.

The book, the money kept in cents, the report and the check stay this program’s own: every total is computed twice, once by SQLite’s own SQL and once by Heroes over the same rows, and the program prints yes only where the two agree to the cent.
