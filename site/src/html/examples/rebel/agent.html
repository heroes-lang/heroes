An AI assistant for a folder of documents: it indexes them, answers questions with a language model, and serves the same tools to other agents.

It cuts the documents into passages measured in a model’s tokens (the pieces a model reads text in), turns each passage into a vector, a list of numbers that puts texts of similar meaning near each other, and keeps them in an index on disk. Asked a question, it gives a model the nearest passages and tools to look further: search, read a file, query a JSON file, count tokens, and run a command the user allowed. It speaks Claude’s Messages API and OpenAI’s Chat Completions, which local servers such as Ollama speak too, falls back from one provider to the other, and serves its tools, documents and a prompt to other agents over the Model Context Protocol.

The output on this page is its demo: the whole session run against stand-ins of both APIs that the program carries, small servers on the machine itself that answer as the real ones would, so it spends nothing. Rebel’s llm/anthropic and llm/openai speak the two APIs, tokenizer counts tokens, chunks cuts the documents, vectors keeps the index, and mcp and jsonrpc serve the tools.
