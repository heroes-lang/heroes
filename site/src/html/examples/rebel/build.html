A build tool in the family of make and ninja, which decides what to rebuild by the content of the inputs, never by file times.

It reads build.toml, its rules, targets and variables, and checks the graph of what depends on what before running anything: a cycle is told by its path and a missing input by every target that needs it. A step runs only when the digest of its inputs or of its command has changed, kept in a log beside the outputs; the dependency files a compiler writes teach it the headers no build file names; and up to -j N steps run at once on worker threads, the first failing step stopping the build.

The output on this page is its demo: a small project whose steps are this program’s own helpers, built, then one input changed and only what depends on it rebuilt, then a cycle and a missing input refused and a failing step stopping a build. Rebel’s graphs orders the steps and finds cycles, hash computes the digests, process runs each command with no shell in between, threads runs the steps side by side, and toml reads the build file.
