The log summariser, written again with Rebel: a file of log lines in, a readable page out, and an exit status that says whether anything went wrong.

Rebel’s strings takes each line apart, its maps counts the lines by level and ranks the counts, ties left in name order, and its math counts the levels set in a mask, each in place of helpers the original writes. The page stays this program’s, and so does its reader, which skips and counts a line it cannot parse rather than refusing the file. It ends with status 1 when the log holds an error, so a script can ask whether anything went wrong without reading the page.
