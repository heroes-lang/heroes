The tiny assembler and its simulated machine, written again with Rebel, printing byte for byte what the original prints.

Rebel’s strings takes each line of assembly apart, its numbers reads the numbers an instruction carries, and its math does the machine’s additions and subtractions, answering an error where the language’s own + and - would stop the program on a result too large for 64 bits. The machine stays this program’s own: one set of constants to encode an instruction and decode it, two passes over the file because a jump may name a label further down, and a step limit that stops a program that would run forever.
