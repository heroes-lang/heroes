The to-do list kept in a file, written again with Rebel’s lists, numbers and strings.

Rebel reads the number after done, the file’s lines and the text of a task, and takes the words after the command, in place of the original’s own helpers. The list and its file stay this program’s: the one write to the disk is in save, and everything that decides what to write is in list.hero, which never touches the disk, so its tests never do either.
