The small relational engine, written again with Rebel: a generated table written as CSV, read back, filtered, joined, ordered, grouped and counted.

Rebel’s csv writes the table and reads it back by RFC 4180, the standard for CSV files, its numbers reads the fields’ numbers and writes a mean to two decimal places, and its lists sorts the rows, keeping rows that compare equal in their order. Each replaces code the original writes, with the C function that program binds to read decimal numbers.

The generator, the strict shape each field is held to, the query kept as a value and the engine stay this program’s own, and so does its check: every number it prints is computed twice by two routes that share no code, because no published answer exists for a table the program invented.
