A file manager in a window of the system’s own widgets: folders, previews, search, bookmarks, a trash, archives and undo.

Its window, built from the buttons, lists and menus the operating system itself draws, shows the tree of folders and the bookmarks, a folder’s entries with their size, type and date written as the person’s language writes them and ordered as that language orders names, and a preview: a text’s first lines in whatever encoding it was saved in, an image decoded with its size, an archive’s members. It searches by name and by content, copies, moves, renames one entry or several by a pattern, deletes to a trash it keeps and can put back, compresses to ZIP or tar.gz and extracts, shows a file’s checksums, numbers computed from its content that change if one byte does, undoes and redoes, shows a progress window with Cancel for every long operation, and follows the folder when another program changes it.

The output on this page is its demo: a scripted session on a tree of files it writes, played on the side of ui that draws no window, printing the window as text after each step. It is not run on Windows, where every path the window shows is written with \ instead of /. Rebel’s ui makes the window, its widgets and its dialogs, fs and fs/watch list, change and watch the files, i18n/collate, i18n/dates and i18n/numbers order and write the listing, unicode/encodings and image make the previews, archive and compress pack and unpack, and containers/ordered keeps the listing in order.
