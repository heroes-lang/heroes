The text adventure, written again with Rebel: the same game played from the same script, printing the same transcript to the byte.

Rebel’s strings reads the script’s commands and cuts the verb from the rest of each line, its graphs walks the map for the test that every room can be reached, and its maps gives a room’s exits, three jobs the original does with helpers of its own. The game stays this program’s: each turn takes the state of the game and gives back the new state and the lines to print, and the program ends by reaching the end of main rather than calling exit, so the tests can still check for memory the program failed to release.
