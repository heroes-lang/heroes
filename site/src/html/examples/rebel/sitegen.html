A static site generator that reads each page’s header as Hugo and Jekyll do: Markdown pages, a theme and images in, a site in several languages out.

A folder holding site.toml, Markdown pages with YAML or TOML front matter (the settings at the top of a page), a theme and static files becomes a site: each page in each of its languages, with dates and numbers written as that language writes them; a home page, a list for each section, an A to Z index ordered as the language orders text, and a page for each tag; images scaled to thumbnails and converted to a kind a browser shows; a sitemap and an Atom feed for each language; and a Brotli copy beside every text file. Its watch mode builds again after each change, running only the work the changed files feed.

The output on this page is its demo: the bundled site written, built and listed, then edits made to it and watched. Rebel’s markdown reads each page, template sets it in the theme, html gives headings their ids and points the links, i18n and its subpackages write each language’s dates, numbers and order, image and its codecs make the thumbnails, xml writes the sitemap and the feeds, compress/brotli compresses, and fs/watch tells the watch mode what changed.
