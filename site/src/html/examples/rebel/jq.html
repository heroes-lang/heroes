A small jq, the tool that filters JSON: one filter run over JSON, or over YAML and TOML as yq does.

The filter language is Rebel’s json/jq, which runs over a json.Value, the one value Rebel reads JSON into. YAML and TOML are read into the same value by Rebel’s own yaml and toml, so one filter reads all three formats, as the tool yq does. The program itself is the part a command-line tool owns: reading its options, the files or the standard input, writing each answer on a line, and ending with the exit codes jq uses.
