A search engine for one website, in the family of a small Meilisearch or Elasticsearch: it crawls the site, indexes it, and serves a search page and an API.

It crawls the site from a start address as a polite crawler does, asking robots.txt and leaving other sites alone, and reads each page’s text as a reader reads it, folded so that accents, case and ligatures never keep a query from a page. It indexes the pages for full-text search ranked by BM25, a standard formula for how well a page matches the words of a query, and as vectors for the queries whose words the pages write otherwise. It ranks pages by the site’s own links with PageRank, folds near-duplicate pages into one result, corrects misspelt words, completes a query as it is typed, and serves a web page and a JSON API.

The output on this page is its demo: a small baking site served on the machine itself, crawled and indexed, the search engine served on a second port, and scripted queries run through its own client, printing a transcript that is the same on every run. Rebel’s http fetches and serves, html and html/sanitize read the pages, search keeps the full-text index, unicode/normalize folds the text, tokenizer and vectors make and hold the vectors, and math/linear computes PageRank.
