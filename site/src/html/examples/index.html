Examples

Browse every example in the repository, with its source code, command and recorded output where available.

The test corpus is the collection of programs used to check the compiler. On every commit, the tests build and run them in three configurations; examples that need an unavailable C library are skipped. Where a page shows recorded output below the command, the tests compare the program’s output with that text byte for byte.

Start with the first group, which introduces one idea at a time in reading order. These files are checked for compilation errors and formatting, but their output is not recorded or tested. The groups after it, up to the last, make up the test corpus, with programs such as a JSON reader, a small language interpreter, a SQLite ledger and calculations using raylib.

The examples are two groups, kept apart so a name cannot be read as the other’s. Every program above the last heading is in examples/ and uses no library: where it needs a function a library would give, it carries its own. The last group, examples-rebel/, holds programs written with Rebel, the library this project writes, each named under rebel/. Where one program is written both ways, each page links the other.
