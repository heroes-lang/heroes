Examples

Every program in the repository, here on the site, with the command that runs it and the output it really prints.

These are not snippets written for a website. They are the programs the compiler is tested against. Each one is built and run in three configurations on every commit, and on each program's page the block under the command is the text those tests compare byte for byte. A program that stopped working would turn a test red before anybody read this page.

Start with the first group: written to be read, one idea each, in order. Everything after them is the corpus, which is where the language does real work: a JSON reader, an interpreter for a small language, a book of accounts in SQLite, a window.
