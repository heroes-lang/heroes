A simple programming language

“Heroes”

Decades of programming-language history, condensed into fewer than 6K tokens.

A compiled language that reads like Python and has all the power of C. No braces, no semicolons. No interpreter, no virtual machine. No nulls, no exceptions. No garbage collector, no heavy runtime. Many of the mistakes models make simply don’t compile here. Mature enough to compile its own compiler. Simple enough to fit in a prompt. What you write becomes a standalone executable.

The compiler reports mistakes

A model writes totl instead of total. In languages that let an assignment declare a variable, a typo like this can create a new variable. Heroes uses different syntax for declaring and updating variables: the compiler rejects the unknown name and suggests a correction: 

error[unknown_name]: nothing named `totl` is in scope — did you mean `total`?
  at tests/golden/check/typo-not-a-new-binding.hero:10:9
     |
  10 |         totl @ total + x  #~ unknown_name
     |         ^^^^
  fix (certain): rename to `total`

The compiler also catches swapped labelled arguments, missing cases and keywords from other languages. Each message identifies the problem and its location in the code. When possible, it suggests a fix; fixes marked certain can be applied automatically. More error examples →

Heroes uses C libraries

Heroes uses C libraries for maths, files, sockets, databases and graphics. A few lines declare the library functions your program needs. Clang, the C compiler, checks these declarations against the library’s header, the file that describes its functions and types. If the types do not match, compilation stops.

The examples include programs that use a database, call a graphics library and send a web request. Their pages also show recorded output where available. Examples using C libraries →

The thesis

A language designed so that every plausible LLM mistake is a compile error will produce working programs in fewer total tokens than a conventional language, even if each program costs more tokens to write.

One part of the thesis has been tested. heroes mutate introduces one realistic mistake at a time into working programs and counts how many the compiler catches. It repeats the test with the Heroes-specific checks disabled. The comparison shows which mistakes those checks catch.

The total number of tokens needed to produce a working program in Heroes and another language, including corrections, still needs to be compared. The tool for that comparison has been designed but has not been built yet. The available results →

Run it · speed of life ·

Heroes is in beta: the language still changes. The version you build below is heroes {{version}}. Until 1.0.0, a change in the middle number can change the language itself, and a change in the last number never does. A program you write today may need small edits later. 

$ git clone https://github.com/heroes-lang/heroes
$ cd heroes
$ clang -I runtime seed/heroes.c runtime/runtime.c -o heroes
$ ./heroes run examples/gallery/03-fallible.hero
read 42
failed: not_a_digit (expected 0-9)
20

The third line builds the compiler from a single C file. It takes under four seconds on a MacBook Air, the machine every measurement here comes from. The Heroes compiler generated that C file, so clang is all you need. The line saying failed is the example refusing a character it cannot read. Who is building it

One person who had never written a compiler before this one and an AI assistant that follows rules stored in the repository, the project’s archive. A panel of five judges reviews every language change; four can veto it. The author approves or rejects each decision. Who wrote this → · how changes are reviewed →

Heroes has no installer yet. Building it takes a C compiler and one command. Every decision, sitting and measurement is recorded in the repository, which is open to read. The licence is Apache 2.0, so you may use it, change it and build on it. Questions and problem reports are welcome there; code contributions are not open yet, and the repository says what has to be true first.

The name is an homage to David Bowie’s “Heroes” (1977), and the quotation marks are his. The lightning bolt is borrowed from 1973, worn at a respectful angle. You will never meet Bowie in an error message.
