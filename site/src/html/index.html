A compiled programming language

“Heroes”

A whole language in one prompt, for the models writing your code. It compiles itself.

  • Designed so that a model’s plausible mistake will not compile.
  • No null, no exceptions, no garbage collector.
  • No standard library: everything comes from C.
  • Native binaries, and no runtime to install.

Mistakes are compile errors

A model writes totl where it meant total. In most languages that line declares a new variable and the program quietly gets the wrong answer. Here it is refused, with the repair attached: 

error[unknown_name]: nothing named `totl` is in scope — did you mean `total`?
  at tests/golden/check/typo-not-a-new-binding.hero:10:9
     |
  10 |         totl @ total + x  #~ unknown_name
     |         ^^^^
  fix (certain): rename to `total`

Swapped arguments of one type, a case left out, a keyword borrowed from another language: none of those compile either. Every error says what was expected and where. Where the repair is known it comes with the message, and one marked certain can be applied by machine. More real errors →

No standard library, on purpose

Maths beyond arithmetic, files, sockets, databases and graphics come from the C libraries the world has used for fifty years. A few lines connect one to your program. Clang checks those lines against the library’s own header, so a wrong type is a compile error rather than a crash later.

A database, a window and a web request are three of the programs on this site, each with the output it really prints. The C libraries, working →

The thesis

A language designed so that every plausible LLM mistake is a compile error will produce working programs in fewer total tokens than a conventional language, even if each program costs more tokens to write.

Half of it is measured. heroes mutate takes working programs, plants one realistic mistake at a time, and counts how many the compiler stops. Then it runs again with the thesis rules switched off, and the distance between the two runs is the result, kept mistake by mistake.

The other half is the token count itself, end to end against another language. That instrument is designed and not yet built. So half the thesis has a number and half is still a question, and this page says which. The measured half →

Run it · speed of life ·

The repository is still private, so the clone below does not work yet. The addresses are final and they open with the code.

$ git clone https://github.com/heroes-lang/heroes
$ cd heroes
$ clang -I runtime seed/heroes.c runtime/runtime.c -o heroes
$ ./heroes run examples/gallery/03-fallible.hero
read 42
failed: not_a_digit (expected 0-9)
20

The third line builds the compiler from a single C file. It takes under four seconds on a MacBook Air, the machine every measurement here comes from. Heroes wrote that C file, so clang is all you need. The line saying failed is the example refusing a character it cannot read. The whole way in → · the language, one idea at a time →

Who is building it

One person who had never written a compiler before this one, and an AI assistant that works to a contract kept in the repository. Neither of them decides the language. Every change goes to a panel first: five judges, four of whom can refuse it outright. Who wrote this → · how a change gets decided →

Heroes is not packaged yet. No installer and no public release, so the way in is a C compiler and one command. Every decision, sitting and measurement is recorded in the repository, still private, opening with the code.

The name is an homage to David Bowie’s “Heroes” (1977), and the quotation marks are his. The lightning bolt is borrowed from 1973, worn at a respectful angle. You will never meet Bowie in an error message.
