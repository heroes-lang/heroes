The specification

The whole language, in the file a model is handed. Take it whole: heroes-lang.org/spec.md, or curl -L heroes-lang.org/spec.md. The block below is the same bytes, and selecting all of it gives you the same prompt.

This is not a summary and there is no longer version. The specification IS the language: when it and the compiler disagree, the compiler has the bug. It stays under a hard ceiling of 4,096 tokens, which a test asserts on every commit, because it has to leave room in the prompt for the program you actually want. Counted with the tokenizers the models actually use, two of them, and the larger of the two is the one that binds.

It is shown here exactly as the file holds it, cut from the repository when this page was built. Not rendered, not tidied: a table with a pipe moved or a backtick turned into a quotation mark would no longer be the thing you paste into a prompt.
