The specification

The complete description of Heroes, ready to include in a model’s prompt. Download it from heroes-lang.org/spec.md or use curl -L heroes-lang.org/spec.md. You can also copy the entire block below: the content is identical.

The specification defines the whole language; there is no longer version. If the compiler behaves differently, the compiler has a bug. On every commit, or recorded change, a test checks that the text stays below 4,096 tokens. Tokens are the pieces into which a model divides text. The count uses two tokenizers, the tools that split the text, and takes the higher result. This leaves room in the prompt for the program you want to write.

When the site is built, this page reads the specification from the repository and displays it unchanged. Table separators, spaces and characters stay exactly as they are in the file, so you can copy it into a prompt without altering it.
