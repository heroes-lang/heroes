The specification

The complete description of Heroes, ready to include in a model’s prompt. Download it from heroes-lang.org/spec.md or use curl -L heroes-lang.org/spec.md. The button under the block below copies it whole; without scripts, one click on the block selects it whole. The content is identical either way.

The specification defines the whole language; there is no fuller version. If the compiler behaves differently, the compiler has a bug. The text stays below 8K tokens, and today it measures {{realTokens}}, counted by {{realModel}}. Tokens are the pieces into which a model divides text. The count is the model’s own, taken through Claude’s token-counting API and recorded with the model that produced it; a test on every commit, the project’s word for a recorded change, holds the recorded count under the ceiling and refuses a text that moved without a new count. Two tokenizers shipped with the compiler, the tools that split the text, print a second count beside it, and the real count is never lower than theirs. This leaves room in the prompt for the program you want to write.

When the site is built, this page reads the specification from the repository and displays it unchanged. Table separators, spaces and characters stay exactly as they are in the file, so you can copy it into a prompt without altering it.

The shape of the document is borrowed from the Report, the short reference text the designers of a language publish, a form that runs from the Algol Report through Wirth’s reports on Pascal, Modula-2 and Oberon to the Scheme reports. Those documents number their sections so that a rule can be cited by number, and the Algol Report kept every number through its revision. This one does the same.
