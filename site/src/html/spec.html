The specification

The complete description of Heroes, ready to include in a model’s prompt. Download it from heroes-lang.org/spec.md or use curl -L heroes-lang.org/spec.md. You can also copy the entire block below: the content is identical.

The specification defines the whole language; there is no fuller version. If the compiler behaves differently, the compiler has a bug. The text stays below 6K tokens, and today it measures {{realTokens}}, counted by {{realModel}}. Tokens are the pieces into which a model divides text. The count is the model’s own, taken through Claude’s token-counting API and recorded with the model that produced it; a test on every commit, or recorded change, holds the recorded count under the ceiling and refuses a text that moved without a new count. Two tokenizers shipped with the compiler, the tools that split the text, print a second count beside it, which the real one never falls below. This leaves room in the prompt for the program you want to write.

When the site is built, this page reads the specification from the repository and displays it unchanged. Table separators, spaces and characters stay exactly as they are in the file, so you can copy it into a prompt without altering it.
