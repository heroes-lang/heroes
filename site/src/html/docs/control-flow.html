Control flow

Choose with if; repeat with for or while.

Control flow is the order in which statements run. Heroes provides if to choose which statements to run, for to iterate over a sequence, and while to repeat a block while a condition is true.

if, and only bool

A condition must have type bool, with a value of true or false. Numbers and strings are not automatically converted to conditions: 

$ heroes check loops.hero
error[not_bool]: an `if` condition must be `bool`, found `i64` — there is no truthiness in this language
  at loops.hero:13:12
     |
  13 |         if x
     |            ^

Use if, else if and else to define branches. The condition needs no parentheses; indentation defines the body. if is also an expression, meaning it can produce a value. You can use it to choose a value without assigning separately in two branches.

for x in xs: walking a sequence

The loop visits one element at a time. On each iteration, the variable holds a fresh copy of that element. There is no index or counter to update.

The next chapter explains the @ symbol. Here best: i64 @ floor declares a mutable variable, and best @ x assigns a new value to it. A name bound with = cannot be reassigned.

Leaving early: break

Skipping one: continue

break ends the innermost loop; continue skips to its next iteration. You cannot name an outer loop with a label. To leave several loops, you can put them in a function and use return to exit it.

while: repeating on a condition

A while checks its condition before each iteration. If a counter needs updating, write that update in the body in the order it should run.

Counting: a range is a function call

range returns a list of numbers, including from and excluding to. You must name both arguments because they share the type i64, as explained in chapter 2.

Use _ as the loop variable when you do not need the element’s value. As in a match, _ discards the value without binding a name, so it cannot produce an unused-name error.

Appending text to a string in a loop copies the entire string each time, so each iteration costs more. For long strings, use repeat or join, which build the result in one pass. The strings chapter explains the difference.
