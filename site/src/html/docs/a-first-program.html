Heroes / Guide / chapter 1

A first program

A file and a main function are enough to get started.

Your first Heroes program needs one file with a main function. You do not need a project file or an imported library to print a result.

The whole program

$ heroes run examples/gallery/00-first.hero
20

function main() defines where the program starts. It takes no arguments and returns no value, so there is no return type after the parentheses. A function that returns an integer declares it with -> i64. print is built in: it prints its arguments one after another, then starts a new line.

What is not in that file

The file contains only the code the program needs. These rules reduce how much information you need to look up elsewhere:

  • No import or include line. print, len and the rest of the built-ins are always available.
  • No class is needed to hold the functions, and no namespace block is needed to group names. The file already groups them.
  • No semicolons and no braces. Line breaks separate statements. Indentation shows which lines belong to a block.
  • No project configuration or build script. Give the compiler the source filename.
  • No forward declarations. Declaration order never matters, so two functions can call each other without either being announced first.

The indentation is the structure

Indent each block by four spaces relative to the line that opens it. The rule applies at every level. A different indentation produces this error: 

$ heroes check hello.hero
error[indentation_not_multiple_of_4]: indentation must be exactly 4 spaces per level; found 2
  at hello.hero:2:1
    |
  2 |   print("hi")
    | ^^

Tabs produce a separate error. Consistent indentation makes versions of a file easier to compare. heroes fmt prints code in the language’s standard format. Files already in that format remain unchanged, byte for byte.

This line associates the name eval with eval.hero in the same directory. Prefix a function with that name to use it: eval.calculate(text, env). Each module needs its own use line; there is no wildcard import to bring in all its names at once. You can rename a module with as, as chapter 13 shows. The prefix and the use line tell you which file to consult.

The verbs

The heroes command provides these subcommands, each with a specific task: 

$ heroes check program.hero    # names and types, no binary
$ heroes run program.hero      # compile and execute
$ heroes build program.hero    # compile only
$ heroes test program.hero     # run the file's tests
$ heroes fmt program.hero      # print the canonical form

Tests are part of the language. The points file shown above contains two: 

$ heroes test examples/gallery/01-points.hero
ok   "the 3-4-5 triangle"
ok   "a rectangle keeps its size when it moves"
2 tests, all passed
