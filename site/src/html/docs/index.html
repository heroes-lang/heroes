Learn the language one concept at a time. You do not need to read the specification first.

How to read this

The specification defines the language rules. It is short enough to fit in a prompt, the text you give a model. These fourteen chapters explain the language in order, one concept at a time. Consult the specification on this site when you need a precise rule.

Every code example comes from a file in examples/. Its filename appears below the block. During the build, the process that generates the site, a check compares each block with its source and stops the build if they differ. On every commit, a change saved in the repository history, these programs are compiled and run in three configurations. Browse the examples and their output →
