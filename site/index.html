“Heroes”

A small compiled language, designed for the reader that reads most code today: a language model.

pre-alpha · being built in the open · nothing to install yet

The thesis

A language designed so that every plausible LLM mistake is a compile error will produce working programs in fewer total tokens than a conventional language — even if each program costs more tokens to write.

Nothing here is taken on faith: the claim is measured, continuously, against a control build of the same compiler with the safety rules switched off.

What it looks like

# A comment adjacent to a declaration is its documentation.
# Squared distance. Avoids sqrt to preserve precision.
dist2 = function: (a: Point, b: Point) -> int
    dx = a.x - b.x
    dy = a.y - b.y
    return dx*dx + dy*dy

Point = record
    x: int
    y: int

test "3-4-5 triangle"
    assert dist2(Point(x: 0, y: 0), Point(x: 3, y: 4)) == 25

The rules it lives by

  • Locality is the currency. The meaning of a line is decided by that line plus the enclosing signature — never by something defined three files away. No inheritance, no macros, no exceptions, no implicit conversions, no null.
  • Exactly one way to write anything. A canonical formatter, one loop keyword, one integer type, mandatory named arguments where types could be confused. Errors that models actually make become errors the compiler actually raises.
  • Errors written to be read by a machine. Every diagnostic carries everything needed to fix the program in one turn — expected type, definition site, concrete fixes. Typed holes (???) let a program be built skeleton-first.
  • No standard library — on purpose. A minimal runtime, native binaries, no GC (refcounting + copy-on-write), and everything else through a C FFI where clang verifies every signature against the real header.
  • Small enough to compile itself. The whole specification fits in ~1500 tokens. The language is finished for v1 when its compiler is written in it — and the bootstrap compiler is retired.

Follow the build

The language is being built in the open, one documented step at a time — design decisions, adversarial reviews, measurements and all: github.com/giuseppearici/heroes-lang.

The name is an homage to David Bowie's “Heroes” (1977) — the quotation marks are his. The irony lives in the prose; the language keeps its keywords plain.
