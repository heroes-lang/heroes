Native binaries, no runtime to install · sound and vision ·

Records, functions, exhaustive match, tests in the language. Compiled through C to a native binary, reference-counted rather than garbage-collected, and no conversion between number widths ever happens on its own. Every code block on this site is a slice of a file in the repository that compiles and runs — including that one.

Three things that make it different

  • Mistakes are compile errors

    Swapped arguments of the same type, a forgotten variant case, a mutated name nobody declared, a keyword borrowed from another language: each one is a diagnostic that arrives with its own repair, not a program that runs and is quietly wrong.

    See a real error

  • No standard library, on purpose

    A minimal runtime and nothing else. Maths, files, sockets, JSON, HTTP, SQL and graphics all arrive from C libraries through one FFI, where clang checks every declaration against the library's own header.

    The founding constraint

  • It compiles itself

    The compiler is written in Heroes — 143 modules, 34,812 lines. Both compilers emit the same 20-megabyte C file, byte for byte, three generations deep. One hash.

    The fixpoint

The claim · quicksand, avoided ·

A language designed so that every plausible LLM mistake is a compile error will produce working programs in fewer total tokens than a conventional language — even if each program costs more tokens to write.

It is a claim, not a slogan, so it is measured — continuously, against a control build of the same compiler with the safety rules switched off. The whole specification fits in 3512 tokens against a hard ceiling of 4096, because the spec is not documentation, it is the prompt. The reasoning, and the answers to the obvious objections →

The name is an homage to David Bowie's “Heroes” (1977) — the quotation marks are his. The lightning bolt is borrowed from 1973, worn at a respectful angle. The section nods are song titles, nothing more: the irony lives in the packaging, and the language keeps its keywords plain — you will never meet Bowie in an error message.
