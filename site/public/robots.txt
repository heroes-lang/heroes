# Everything here is open to everything, and the blocks below say so by name.
#
# `User-agent: *` already allows every crawler that exists, so naming the model
# crawlers changes no behaviour at all. It is here because silence is the one
# answer this site cannot give: a language whose whole point is being read by a
# model, staying quiet about the crawlers that feed models, would be leaving its
# own position to be guessed. The tokens are the ones each vendor documents,
# read from their own pages rather than recalled.

User-agent: *
Allow: /
