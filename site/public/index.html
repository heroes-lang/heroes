A compiled programming language

“Heroes”

Every plausible LLM mistake is a compile error.

Made for the machines that write code now, yet plain to human eyes. No standard library, no garbage collector, native binaries, and it compiles itself.

Native binaries, no runtime to install · sound and vision ·

That is a tree that contains itself, in a language whose data model has no pointer and no reference type: the array is the only indirection there is, so the whole thing still copies like a value. It is compiled through C to a native binary, and reference-counted rather than garbage-collected.

Every code block on this site is a slice of a file in the repository that compiles and runs, including that one.

Run it

$ git clone https://github.com/giuseppearici/heroes-lang
$ cd heroes-lang && cargo build
$ ./target/debug/heroes run examples/gallery/03-fallible.hero
read 42
failed: not_a_digit (expected 0-9)
20

The middle line of that output is a failure being handled, not the build breaking. The chapter on it walks through that program line by line. There is no installer yet: building from source is the only way in, and it is the supported one. It needs rustup and clang: the repository pins Rust 1.90.0 and rustup fetches it on the first build, and there are no third-party crates, so nothing else is downloaded. Once built, ./target/debug/heroes doctor checks the other half: clang, the linker, the architecture, the runtime and the build cache.

Then write your own. The file needs nothing else: no imports, no header, no project file, just a main. 

$ printf 'function main()\n    print("we can be heroes")\n' > hello.hero
$ ./target/debug/heroes run hello.hero
we can be heroes

heroes run compiles that to a native binary and executes it, from any directory, leaving its intermediate files in a build/ folder beside you. Every capability is a subcommand of that one binary: lex, parse, check, build, run, test, fmt, doctor, mutate, measure, this, and every example on this site is a file in examples/, waiting to be changed.

Three things that make it different

  • Mistakes are compile errors

    Swapped arguments of the same type, a forgotten variant case, a mutated name nobody declared, a keyword borrowed from another language: each one is a diagnostic that arrives with its own repair, not a program that runs and is quietly wrong.

    See a real error

  • No standard library, on purpose

    A minimal runtime and nothing else. Maths, files, sockets, JSON, HTTP, SQL and graphics all arrive from C libraries through one FFI, where clang checks every declaration against the library's own header.

    The founding constraint

  • It compiles itself

    The compiler is written in Heroes, 143 modules, 34,812 lines. Both compilers emit the same 20-megabyte C file, byte for byte, three generations deep. One hash.

    The fixpoint

A small surface, no collector, and no crash

Four words can begin a top-level line: constant, function, record, variant. That is the whole inventory. No classes, no interfaces, no module blocks inside a file, no mutable globals, and declaration order never matters. Underneath it, the language the compiler implements is seven constructs; everything else you can write is sugar that disappears before the compiler's internal form, which is how one person finishes a compiler.

Memory is managed without a collector: every value behaves as a copy, with reference counting and copy-on-write underneath. Because a reference cannot be stored anywhere, cycles cannot be built, so the counting cannot leak. No garbage collector, no weak annotations, no pause. And a program must not segfault or corrupt memory, which is a goal of the language rather than a quality of its implementation: overflow, an index past the end, a division by zero, each is a deterministic abort rather than undefined behaviour. The claim · quicksand, avoided ·

A language designed so that every plausible LLM mistake is a compile error will produce working programs in fewer total tokens than a conventional language, even if each program costs more tokens to write.

It is a claim, not a slogan, so it is measured, and the measurement is never one number. heroes mutate injects one plausible mistake at a time into working programs and counts what the compiler catches, then runs the same corpus against itself with the thesis rules switched off. The gap between the two columns is the whole result, per mistake, measured 2026-08-18: 

                        with the rules   without
a dropped argument label        91%         0%
a shadowed name                100%         0%
a lazy catch-all on a variant  100%        39%
two same-typed arguments        80%        43%
a typo in a name               100%       100%

The last row is the honest one: typos are caught by names and types in any language, and the rules add nothing. That is why the project refuses to average these into a single figure: an average hides both the operators where the design does everything and the ones where it does nothing. Heroes is pre-release and built in the open: the fixpoint is measured, the Rust bootstrap is not yet archived, and there is no installer, the compiler builds from source. The record of every decision, panels and measurements included, is public in the repository.

The name is an homage to David Bowie's “Heroes” (1977), and the quotation marks are his. The lightning bolt is borrowed from 1973, worn at a respectful angle. The section nods are song titles, nothing more: the irony lives in the packaging, and the language keeps its keywords plain. You will never meet Bowie in an error message.
