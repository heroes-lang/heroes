A compiled programming language

“Heroes”

Small enough to fit in a prompt, real enough to compile itself.

Made for the machines that write code now, yet plain to human eyes. No standard library, no garbage collector, native binaries — and every plausible LLM mistake is a compile error.

Native binaries, no runtime to install · sound and vision ·

That is a tree that contains itself, in a language whose data model has no pointer and no reference type: the array is the only indirection there is, so the whole thing still copies like a value. It is compiled through C to a native binary, and reference-counted rather than garbage-collected.

Every code block on this site is a slice of a file in the repository that compiles and runs, including that one.

Run it

There is no installer, and there is nothing to install. The repository carries the compiler as one generated C file, so a C compiler is the only thing your machine needs: 

$ git clone https://github.com/giuseppearici/heroes-lang
$ cd heroes-lang
$ clang -I runtime seed/heroes.c runtime/runtime.c -o heroes
$ ./heroes run examples/gallery/03-fallible.hero
read 42
failed: not_a_digit (expected 0-9)
20

That C file is not a hand-written bootstrap. It is what the compiler prints when it compiles itself, so the thing you just built is the language building the language, with no other toolchain in the room. ./heroes doctor checks the rest of what a build needs: clang, the linker, the architecture, the runtime and the build cache.

The middle line of that output is a failure being handled, not the build breaking. The chapter on it walks through that program line by line.

Then write your own. The file needs nothing else: no imports, no header, no project file, just a main. 

$ printf 'function main()\n    print("we can be heroes")\n' > hello.hero
$ ./heroes run hello.hero
we can be heroes

heroes run compiles that to a native binary and executes it, from any directory, leaving its intermediate files in a build/ folder beside you. Every capability is a subcommand of that one binary: lex, parse, check, build, run, test, fmt, doctor, mutate, measure, this. Every example on this site is a file in examples/, waiting to be changed.

Three things that make it different

  • Mistakes are compile errors

    Swapped arguments of the same type, a forgotten variant case, a mutated name nobody declared, a keyword borrowed from another language: each one is a diagnostic that arrives with its own repair, not a program that runs and is quietly wrong.

    See a real error

  • No standard library, on purpose

    A minimal runtime and nothing else. Maths, files, sockets, JSON, HTTP, SQL and graphics all arrive from C libraries through one FFI, where clang checks every declaration against the library's own header.

    The founding constraint

  • It compiles itself

    The compiler is written in Heroes: 155 modules, 38,004 lines. Ask three generations of it to write the same program out in C, and the three files match to the byte. The language it was first built in has left the repository.

    How it compiles itself

A small surface, no collector, and no crash

Four words can begin a top-level line: constant, function, record, variant. That is the whole inventory. No classes, no interfaces, no module blocks inside a file, no mutable globals, and declaration order never matters. Underneath it, the language the compiler implements is seven constructs; everything else you can write is sugar that disappears before the compiler's internal form, which is how one person finishes a compiler.

Memory is managed without a collector: every value behaves as a copy, with reference counting and copy-on-write underneath. Because a reference cannot be stored anywhere, cycles cannot be built, so the counting cannot leak. No garbage collector, no weak annotations, no pause. And a program must not segfault or corrupt memory, which is a goal of the language rather than a quality of its implementation: overflow, an index past the end, a division by zero, each is a deterministic abort rather than undefined behaviour. The claim · quicksand, avoided ·

A language designed so that every plausible LLM mistake is a compile error will produce working programs in fewer total tokens than a conventional language, even if each program costs more tokens to write.

It is a claim, not a slogan, so it is measured. heroes mutate takes programs that work, plants one realistic mistake at a time — two same-typed arguments swapped, a case left out of a match, a name reused — and counts how many the compiler stops. Then it does the same run with the thesis rules switched off, and the distance between the two runs is the result, kept mistake by mistake: some mistakes only the thesis catches, some any language would catch, and one nothing catches yet. An average would hide exactly that, so there is none.

Heroes is built in the open and it is not packaged yet: no installer and no releases, so the way in is a C compiler and one command. The record of every decision, panels and measurements included, is public in the repository.

The name is an homage to David Bowie's “Heroes” (1977), and the quotation marks are his. The lightning bolt is borrowed from 1973, worn at a respectful angle. You will never meet Bowie in an error message.
