How to read this · hunky dory ·

Heroes has a specification, and it is deliberately not a teaching text: it is the control instrument, budgeted to the token so that the whole language fits in a prompt. Reading it teaches you the rules the way a rulebook teaches a game. These pages are the other thing — one idea at a time, in order, with the reasoning left in.

Every code block in this documentation is a slice of a file in the repository that compiles and runs. Nothing here is typed into the page and hoped for. Each block names its file underneath, so you can open it, run it, and change it — and so that a check can tell us the day the documentation stops matching the language.
