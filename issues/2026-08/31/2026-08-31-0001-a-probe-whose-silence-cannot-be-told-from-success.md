2026-08-31 | **A probe whose silence cannot be told from success measures nothing, and three rounds of Windows diagnosis rested on one** (M-argv-execution step 10). The CI probe ran `build --emit-c -o path` and printed both streams; `-o path` writes to the path and says nothing, so the log was empty on Darwin and Linux too, where the emission works. Read as evidence for three rounds. What replaces it asks for the exit code and for the file's existence, which are the two things an answer can be read off, and a second step asks the smallest version of the question first — `heroes test` on a three-line program — before anything the size of a compiler module. The general rule is the one CLAUDE.md §1 already states about negative claims, applied to instruments: an instrument is admissible only if a failure and a success look different through it.
