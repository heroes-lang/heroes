2026-08-05 | **The ownership pass moves, it does not release.** An owning temporary is *moved* into a synthetic slot in the block that defines it, so nothing is owned by a temporary past its own instruction, nothing owned crosses a block edge, and every release is a slot's — at a point already known. Panel 021's costing (release at the end of the defining block, made safe by a checked invariant) was refuted by that very invariant on two real programs within the hour: `.must()`, `?`, `&&` and `if`-as-an-expression all open a block in the *middle* of an expression, so `name + " scored " + got.must().to_str()` builds a concatenation in one block and consumes it in another. The consequence is a uniform reading — **every value that reaches a store is borrowed** — and the cost is over-retention, not a leak, because a loop's synthetic slot is overwritten each iteration | the alternative was liveness, which is the analysis that choosing slots over phi nodes (panel 019) existed to avoid; this cashes that decision properly | Part 5, §4.10 | 019, 021 |
