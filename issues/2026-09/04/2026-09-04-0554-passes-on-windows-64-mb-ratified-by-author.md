  **CLOSED 2026-09-04 by convening `docs/panel/107-the-number-cannot-be-uniform-the-abort-can.md`** (full panel, five judges, on the author's instruction *"option (a), with a panel"*). **The sitting refused all three shapes this item offered, each on a measurement, and adopted something larger.** (a) is not implementable: GNU ld answers `warning: -z stacksize=0x4000000 ignored`, lld answers `unknown -z value`, `PT_GNU_STACK` `p_memsz` stays 0x0 and the depth is **388 with the flag and 388 without**, while `selfhost/cli/toolchain.hero:106-109` forwards a successful clang's stderr, so the warning would print on every Linux build of every program forever. (b) — write the asymmetry down as deliberate — is half adopted and was the *conservative* resolution, which CLAUDE.md §4 forbids taking when a more robust one exists: changing nothing satisfied every veto and would have left the actual §1.12 defect standing. (c) never reached a vote. **What the sitting found instead**, independently in both seats that compile: `hero_stack_lo/hi` (`runtime/parts/stack.c:107-108`) are the **main thread's**, set once, so overflow inside SDL's audio callback is **exit 132 with an empty stderr** where the main thread says `panic: stack exhausted in deep.down` at 134 — and the proposal would have widened that gap from **16:1 to 128:1**, with the loud side being the side already safe. So the bounds and the alt-stack become **per thread**, and the uniformity a program gets is a named abort everywhere rather than a number. **The number cannot be made uniform and that is measured**: Darwin's libpthread pins library threads at 524,288 bytes whatever is done, `ulimit -s unlimited` on Linux gives *less* than a finite value, the flag **overrides the operator** and is granted **above the hard rlimit**, and the same 64 MB is 248 levels for one legal program and 2,537 for another. **Principle 0 has no ticket for the size**: the compiler checks its own 178 modules at exit 0 with **896 KB**, so the deepest Heroes program in existence needs under 1 MB against POSIX's 8. The direction that does have a ticket is the emitter — 344 hoisted locals, 26 KB a level. **And this item's own recommendation was wrong**, which is worth recording: (a) was recommended because the number already existed as a ratified decision and *"the only thing keeping it from the other two platforms is that nobody asked"*. Nobody asking was not the reason. Two of three platforms cannot take it, and the third takes it in a way that overrides its operator. That is what a sitting is for, and it is why this went to one instead of to a commit.
