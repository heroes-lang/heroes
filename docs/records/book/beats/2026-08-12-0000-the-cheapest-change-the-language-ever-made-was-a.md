2026-08-12 | M8a | The cheapest change the language ever made was a verb. Splitting a program into files needs rules: what happens when a file's own name collides with the name of a file it imports, and what happens when an import is never used. Both were already written down — the language says a name may not be reused while it is visible, and that anything bound and never read is an error — so the whole question was which word to use for what an import does. The panel chose *binds*, the same word the language already uses for ordinary values, and the two existing rules covered both cases with nothing added. Eleven of that session's thirteen decisions cost nothing at all; the two that cost anything bought a legal example and a rule about what an import does not give you for free.
