LLVM — whose whole existence is single-assignment form — tells the authors of new languages not to build it: use stack slots and loads and stores, it says, and let a later pass clean up, because that is what clang itself does. QBE says phi nodes are not necessary. Rust's own middle representation chose the plain form in 2015 for the sake of error messages rather than speed and has not changed in eleven years. Every migration anyone could verify was made to produce faster machine code — the one thing this project has formally renounced. The simpler answer had a decade of evidence behind it and nobody had gone looking.
