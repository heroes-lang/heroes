2026-09-02 | M-package-layout | For a month the language had one rule about where files live: a module is one word, and every `.hero` a program reads sits beside the file that names it. Breaking that rule took three sittings in one day, and the third one was called because the author looked at the answer the first two had given and asked whether the name couldn't just be the folder and the file joined together. It could. It was better on almost every number anybody measured — a hundred and twenty-seven modules out of a hundred and twenty-seven would have kept the exact name their four thousand call sites already wrote, the collisions would have gone to zero, and the specification would have got shorter. Four of the five judges approved it. It was refused anyway, on the one argument nobody else had made: the rule already shipped can be widened later, and this one could only be swapped, and swapping it rewrites every program ever written in the language. The judge who made that argument was the one who reads history, and the author's instruction was to follow it. What the day actually taught is smaller and lives in the formatter. A new word entered the language and reached six different pieces of the compiler one at a time, and the sixth was `heroes fmt`, which rewrites your file for you: it did not know the new word, so it deleted it, silently, from a program that worked. And the guard that exists to catch exactly that — the formatter refusing its own output when the output means something different — was looking through the same broken window, so it saw two identical pictures and said nothing. One forgotten line, two places, and the second was the watchman.
