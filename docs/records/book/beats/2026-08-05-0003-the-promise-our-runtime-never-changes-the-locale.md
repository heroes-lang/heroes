2026-08-05 | M5b | The promise "our runtime never changes the locale" turned out to be worth nothing, and the demonstration is more convincing than the argument. Set a locale that writes decimals with a comma — which any of a dozen C libraries does on startup — and the number formatter emits a comma, then notices there is no decimal point, then appends one, producing something that is not a number in any locale. And the self-check cannot see it, because the same setting corrupts the reader as consistently as the writer. The precedent is twenty years old and exactly this shape: Python never touched the locale, the graphical toolkit it was embedded in did, and Python broke anyway.
