The compiler checks that the values a program hands to a foreign function are the widths that function actually takes; that check is built by writing a small function nobody calls, whose parameters are the declared types. The table that spells those types had never been taught about the new kind of value, and the code that builds the list gives up entirely if any one entry is unspellable. So a single unfamiliar argument silently deleted the check for every other argument of that function — four correct-looking numbers going unverified because of a fifth. It was proved by a test file written that same morning, which passed. The tell was small and would have been visible to anyone looking for it: a sister table, answering the same question one file away, had been taught about the new kind and this one had not. Two lists that must agree, and only one of them was updated.
