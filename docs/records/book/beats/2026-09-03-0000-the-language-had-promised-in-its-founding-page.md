2026-09-03 | M-robustness-guards | The language had promised, in its founding page, that a program written in it would not crash and would not wreck memory. On the third of September one sitting read twelve open questions against the repository and measured four places where that promise was a sentence and not a fact. You could hand a value the program had never marked as changeable to a function that changed it, and the compiler said nothing while the memory underneath was corrupted. A fix the compiler called certain rewrote a working program into one that did not build, and rewrote it again each time it was asked. A C function that wanted eight bytes could be given four, and whether the compiler noticed depended on which machine you were sitting at. And a program that called itself too many times simply died, with no word at all, on every platform. The author's answer to all of it was one sentence, given four ways: take the robust road, not the cheap one, on every platform, and never silence an error. So the milestone was six guards. Passing a fixed value as changeable is now a compile error in all eight shapes it could take. The certain fix became a guess, and the instrument that was supposed to catch it learned to read programs made of more than one file. The C boundary went strict in every direction — the same verdict on every clang, a minimum clang written down with its reason, the width and the sign of what a pointer points at read out of the C header itself and held against what the program says — and a complaint clang makes about the author's own declaration is now the author's error on the author's line, not the compiler blaming itself. Deep recursion stops with a sentence that names the function, on the Mac and on Linux, and with a sentence on Windows too, where the stack is eight times larger and the test had to recurse ten million times to find its end. The test harness stopped sharing one scratch folder between two runs, and a blessing now checks that the bytes it is about to freeze came from the program it names. And the one hazard a sitting had knowingly accepted — a file compiled from below its program's root reads its neighbours from the wrong place — is pinned by a fixture that shows both what it says and what it silently does. Two things the day taught that no plan had: an optimiser that seemed to turn recursion into a loop was only making each step cheaper, and one measurement at one depth had been written down as a law; and Windows holding a hundred thousand frames without complaint was found by the platform, not by the reasoning, on the one test row nobody had expected to fail.
