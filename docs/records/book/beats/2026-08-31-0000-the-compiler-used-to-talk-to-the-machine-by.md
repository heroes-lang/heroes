On Windows the shell reads a different language, so the very first sentence — `mkdir -p build` — made a directory called `-p` and everything after it was downstream of that. The fix was not to learn cmd.exe's grammar: it was to stop writing sentences. A program is now handed a list of words, the platform difference lives in twenty lines of C where a platform difference is an ordinary thing to write, and the hand-maintained quoting function that had 189 uses has none. What the day actually taught is smaller and worse: three defects were sitting in code that runs on Darwin every single day, and only Windows could see them, because all three were about what a failure SAYS and nothing ever failed. A message thrown away, an error passed up without a word, eight different stopping points all calling themselves "a stage". Windows was not the bug. Windows was the first reader.
