2026-08-18 | M-harness-port | Everything that checks whether the compiler is right was written in the language the compiler is being replaced with, and all of it would have died on the same afternoon. So it was rewritten in the language itself — six hundred and eighty-eight checks, three and a half thousand lines, a program that runs the compiler the way a person does: type a command, read what comes back, compare it to what was promised. The moment it was pointed at the new compiler testing itself, it went red on two things nobody could have seen before. One was an error message with nothing in it — no code, no line, no piece of the program underneath — printed in the one situation where the compiler is allowed to say *your* mistake, so the reader was told a library was missing and not which line had asked for it. The other was stranger and better: the underline that marks where an error is was too long, and the file that recorded what the message should look like had been storing that wrong length as correct since the day it was written. No review found it. What found it was a second implementation disagreeing — the new compiler drew the underline correctly, so the old one's record of itself was exposed by being contradicted. The rest of the day was full of the same lesson in miniature. A count written down by looking at the screen instead of running the count: wrong twice, caught twice by an assertion that prints what it actually found. A rule about how long a file may be, ported straight across, would have been red on its first run for seventeen files — because in this language the tests live inside the file they test, and because some files cannot be split at all: the language forbids two modules from calling each other, so a knot of mutually recursive code is one file or nothing. The rule that cannot be obeyed is not a standard, so it became a ceiling per file: this one is this long today, and it may not get longer. And a shell command with a redirection at the end, written the obvious way, sent half its output to the terminal instead of the file — found within a minute by the net's own tests, which is the whole argument for building the net before you need it.
