2026-08-10 | M5d | The last two types in the language were entangled, and one of them may not survive. Looking a key up in a map returns "the value, or an error", so the map could not be built before that type existed — and that type turned out to be reference-counted even when it holds a plain number, because its error side carries two strings. So `int?` owns memory. The other half of the tangle is a judgement nobody has made yet: an earlier review found that the map cannot be added to, which means the compiler this language is meant to compile cannot build a symbol table with one, and deleting the whole container from the specification would give back more budget than finishing it costs. The container was built anyway, on the author's instruction, with the disagreement written down rather than smoothed over. If the audit deletes it, this work goes with it, and the record will say that was known in advance.
