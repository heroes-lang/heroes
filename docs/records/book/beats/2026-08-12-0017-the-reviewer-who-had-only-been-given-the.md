2026-08-12 | M-literal-bases | The reviewer who had only been given the language's description, and had been asked about something else, wrote down the way everyone writes file permissions — a zero, then seven, then two more zeros — and asked what it meant. Nobody had ever asked. It meant seven hundred. In every language this one borrows from, and in every example of file permissions ever written, that same run of characters means four hundred and forty-eight; here it silently meant something else, and a program using it would have compiled, run, set the wrong permissions, and passed its own tests. The whole point of the language is that a mistake like that cannot survive to run. The repair chosen was not the obvious one. The obvious one is to refuse the ambiguous form and explain; the one taken also gives the old meaning a spelling of its own, so the same three lines of description close the hole and add the notation the project wanted anyway. Three other languages each reached that answer separately, and always after being bitten.
