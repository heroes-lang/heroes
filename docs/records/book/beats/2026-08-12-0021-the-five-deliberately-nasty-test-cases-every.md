2026-08-12 | M-sized-integers | The five deliberately nasty test cases every milestone owes were written last, as usual, and one of them broke the feature. The language now refuses to squeeze a number into a box too small for it — that is the entire point of the addition — and the check had been written by reasoning about which boxes need which comparisons. For boxes that hold negative numbers the reasoning had a hole: the floor was never checked at all, so a number below the floor slid in unnoticed. A silent wrong answer, inside the mechanism built to abolish silent wrong answers, found by the only tests written specifically to be unkind.
