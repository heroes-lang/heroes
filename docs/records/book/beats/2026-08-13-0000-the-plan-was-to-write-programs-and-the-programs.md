2026-08-13 | M-program-corpus | The plan was to write programs, and the programs turned out to be a way of looking at the compiler. Seven of them were written — a JSON reader, a Markdown converter, a spreadsheet, a maze solver, a small assembler with its own machine, a log summariser, a list of things to do, a game — and six faults fell out of the compiler on the way, none of which any existing test could have found and none of which anybody found by reading. The first one appeared inside a minute: the compiler simply stopped, forever, on a program whose first line named a thing the language reserves. Three of the six are the same fault wearing different clothes, and it is the one this project keeps writing rules about: a decision that was correct when it was made, resting on something about the world rather than on something about the thing in front of it, and going quietly wrong later while the sentence explaining it still reads perfectly. The sharpest of the three sits under a comment saying, in so many words, that this exact thing must never be allowed to happen — and the contradiction was twenty lines further down the same page. It had been true. It had been read. Somebody had agreed with it. What it described had stopped being the case.
