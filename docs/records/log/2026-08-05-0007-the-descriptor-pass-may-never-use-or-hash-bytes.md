2026-08-05 | The descriptor pass may **never** use `memcmp` or hash bytes: `record Flag { n: int, on: bool }` carries 7 padding bytes, so two `==`-equal records hash differently with no compile error and no sanitiser report. And `hash` is generated for **every** type, never null — a call through a null `hash` is `SEGV on unknown address 0x0, pc 0x0`, with no type name and no source line. Go's cheaper rule (emit `hash` only for map-key types) reintroduces the null and is rejected on that ground. A payload-free variant case is omitted from the union, because C11 has no empty struct.
