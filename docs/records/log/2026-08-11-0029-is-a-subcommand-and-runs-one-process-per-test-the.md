2026-08-11 | **`heroes test` is a subcommand and runs ONE PROCESS PER TEST.** The shape is CLAUDE.md §10's stopping rule applied mechanically — it answers a different question about the same input, and its artifact class is a verdict per test where `build`'s is a binary and `run`'s is a process. The process-per-test is not a style choice: an `assert` is a **panic** (§4.18), so a runner that called the blocks in sequence would stop at the first failure and hide every test after it, which is the one thing a test runner must not do.
