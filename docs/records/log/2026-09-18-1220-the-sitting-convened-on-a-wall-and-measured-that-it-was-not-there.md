## Three refusals, each dead a different way

**A call typed by context.** C cannot return an array, so `repeat(0, 256)` would
have to be erased at compile time, and `grep -rn "const_eval\|constant_fold"
selfhost/` returns nothing.

**A zero default.** 120 to 180 lines across six modules, and design.md §4.9 says
no default values. The mechanism panel 162's seat reported as already present is
`(Color){0}` inside a `_Static_assert` — a C11 type probe in an expression that
is **never evaluated**, true as a string and false as a mechanism.

**An out-parameter needing no initial value.** Rust shipped it and withdrew it in
writing: *"immediate undefined behavior … including integer types and arrays of
integer types, and even if the result is unused."* Zig keeps it only with a
mandatory keyword and runtime poisoning. POSIX's commonest out-parameter idiom is
value-result, and `getsockname` was measured returning success while writing
nothing. And this repository already records the hazard: a deleted out-cell store
printed the same four lines at `-O0` and under both sanitisers, because the
indeterminate local happened to be zero.

## The rule the sitting earned, and where it now lives

Six of the brief's premises were false. Three shared one shape — *the compiler
does not have X* — and every one was written by a coordinator who had a shell and
did not run it. CL-077 binds a brief's NUMBERS to a command run while the brief
is written; it says nothing about the other half.

**A brief's negative sentences are run, or they go out as questions.**

Written into `.claude/skills/panel/SKILL.md` beside CL-077 rather than left as a
sentence in a record, because a rule with no executor is the failure this
