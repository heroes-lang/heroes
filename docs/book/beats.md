# Story beats — raw material for the mini-book

One line per beat: `date | milestone | the beat`. Append-only; never polish
here — polishing happens in the book.

2026-08-03 | pre-M0 | The author arrived with a 2000-line design document written with an AI in a long conversation, and asked for a plan "senza scrivere il compilatore". The first real decision was which language would write the language.
2026-08-03 | pre-M0 | Swift won on paper (the semantic mirror of Heroes), lived for about an hour, and died to a one-line question from the author: "ma se devo usare QBE non è meglio scriverlo in C?" — which reopened the backend question instead.
2026-08-03 | pre-M0 | QBE — chosen in the design document for its learning value — was killed in one conversation. Not for speed: because with C emission, clang checks the FFI signatures against the real headers, and the FFI was the founding constraint all along. The design document had already written the escape hatch ("the design to steal from if the backend ever changes to C emission"); we just walked through it.
2026-08-03 | pre-M0 | The author, three times in one afternoon: one command like zig, everything in English (but talk to me in Italian), keep the surface tiny enough to compile itself. Constraints, not features.
2026-08-03 | pre-M0 | The plan was sent to five hostile expert reviewers before a line of code existed. Three said "object". The prediction protocol was cued (the answer written above the blank), the thesis metric had no control arm, and two whole compiler passes were missing. The plan that survived is revision 2.
2026-08-03 | M0 | Day zero produced no compiler and four hand-written C programs — the targets the compiler must hit. The machine found the first design bug before any human: clang warned that the entry label was never used, so every generated function now enters with an explicit goto.
2026-08-03 | M0 | The spec came in at ~1496 estimated tokens against a budget of 1500. The design document had said "the budget is nearly spent" — it wasn't kidding.
2026-08-03 | M0 | The uncued-essay prediction met the author's keyboard and lost. The protocol went low-typing: closed questions, clicks, dictation — retrieval kept, prose dropped. And the first prediction's divergence was the instructive kind: the predicted loop shape was the rotated form that real optimisers emit; the naive form won on purpose.
2026-08-03 | M0 | The teaching protocol died of its own weight on day two. Eight author-gates per step, rules stated in five places each — and the author asked for the keys back: "decido io dove voglio capire, preferirei farlo dopo." The simplicity judge had given the ceremony 0.85 odds of being abandoned within a month; it lasted a day. What survived is a queue: the work never waits, the understanding never expires.
2026-08-04 | M1 | The first real compiler code found the first real design bug in a day: the terminator rule cited Go but had dropped three of Go's words in transcription. The panel earned its keep on the fix — the obvious continuation rule would have silently killed every record body in the language, and the one judge who reads only code caught it. Meanwhile `let x = 5` learned to fail with the answer attached: the thesis is no longer prose.
2026-08-04 | M1 | Writing the string lexer to the letter of the design revealed the design had no letter: nobody had ever written down what `\n` meant, so it meant nothing — the language could not put a double quote inside a string at all, and `print("a\nb")` cheerfully printed four characters. The panel gave back five escapes and, more importantly, took the backslash away. Then the test found the joke in the fix: `"C:\temp"` still can't be caught, because `\t` is perfectly legal.
2026-08-04 | M1 | The project spent two days defending a token budget it had never measured, because measuring was assumed to need an API key the author refused to use. A judge sent to decide how much of the thesis to abandon came back twenty minutes later having simply counted the thing: 1989 tokens, not the 1496 everyone had been pricing against. The 1500 ceiling had been breached the day it was written, and nobody could see it. The design document had said from its first draft: count it with a real tokeniser, not by estimation.
2026-08-04 | M2 | The parser's first act was to discover that the language could not write down the type of a function. `fn` was in the registry of foreign words — an error with the repair pre-written — and also in the spec's own syntax for a function type, so `(fn(int) -> int)` failed to lex and every function-typed parameter in the language was unwritable, `map` and `fold` included. Five judges were sent the question with a recommendation attached, and four of them refused it: the project's own §4.17 lists `fn` among the mistakes the registry exists to catch, seven ancestor languages spell a function type with the word that declares a function, and the tokeniser measures the two spellings identically. The recommendation lost to the evidence, which is what the panel is for.
2026-08-04 | M2 | Then the acceptance program — the calculator in the appendix, written months of conversation before any compiler existed — was fed to the parser for the first time. It found the same class of bug from the other side: a variant case called `.var`, a name the registry had quietly reserved. Two lines later it found a form nobody had specified, `=> assert false`, used in eight places. A 317-line program that had never been compiled turned out to be the best test in the repository, because it was the only one written without the parser in mind.
2026-08-04 | M2 | The formatter turned "canonical" from a slogan into three decisions with prices. Minimal parentheses need associativity, the half of the precedence table nobody writes down. Long lines can only break inside brackets, because panel 007 left nowhere else. And the blank line between a comment and the declaration below it cannot be normalised at all — that gap is what makes the comment documentation, so a formatter that tidies it changes what the program means.
