2026-08-15 | M-struct-passing | Three separate places in the compiler broke on the same day for the same reason, and none of them was a mistake anyone made. Each was a list of cases with a catch-all at the end, written when the case that now falls into it did not exist. One made the tidying tool quietly rewrite a program into a different program that still looks legal. One made a conversion produce a result meaning "this succeeded, and the answer is zero" for every input, at no complaint from anything, because the empty space it left behind happens to spell success. One made the compiler blame itself, in public, for something the author had done. The project has a written rule about decisions that rest on an assumption about the world rather than on the thing in front of them, and the rule says to write the assumption down so it can be checked later. What this day showed is that the most dangerous version is the one where nothing is written down at all: a catch-all is an assumption nobody stated, and the day it stops being true, nothing anywhere changes colour.
