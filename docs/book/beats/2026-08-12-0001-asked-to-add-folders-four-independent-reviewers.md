2026-08-12 | M8a | Asked to add folders, four independent reviewers counted instead of arguing, and the count said no. The reasoning that asked for them was that a compiler written in this language would otherwise start with forty files in one directory, which sounds untidy. But a folder does not remove a single import line — it changes how a target is spelled, never whether you have to name it — and the compiler being ported has forty of its files sharing a last name with another, every one of which the folder rule would refuse and force renamed anyway. The clinching fact came from history: the Nim compiler has run with a hundred and seventy files in one directory for years. The request was to decide immediately; the answer was that the thing being feared does not happen.
