2026-08-12 | M-literal-bases | A rule that had been true for a year was one week from becoming false without anything going red. The project measures itself by deliberately breaking its own example programs one small change at a time and counting how many the compiler catches; one of those changes moves the last digit of a named number. Finding the last digit meant asking "is this character a digit", which was a complete question while numbers were only ever written in tens. The moment numbers could also be written in sixteens, a mask ending in a letter would simply have been skipped — the tool would have reported a smaller job and a perfect score on it, and the number it reports is the one the previous milestone had made its headline. Nothing would have failed. The fix was written before the first such number existed anywhere in the project, which is the only time it is cheap.
