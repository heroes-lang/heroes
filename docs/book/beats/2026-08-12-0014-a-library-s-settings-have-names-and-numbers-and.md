2026-08-12 | M-header-constants | A library's settings have names and numbers, and the language could only say the numbers. To tell a download library which address to fetch, a program had to write 10002 — a number that means nothing to anybody, sitting in the file with a comment above it explaining that the library's own documentation adds two to ten thousand. The comment was arithmetic somebody had done by hand, and nothing anywhere checked either the sum or the copy. The project measured how bad that was before fixing it, by building a tool that changes one digit of such a number and seeing whether anything complains: five numbers in the example programs, and nothing complained about any of them. A changed digit produces a program that compiles, runs, asks the library for a setting nobody meant, and reports success. The cure is to stop writing the number: the program names the setting and the library's own description supplies the value, so there is no digit in the file left to be wrong. The comment explaining the arithmetic was deleted along with the number it explained, which is the part worth noticing — an explanation that only exists because something cannot be checked disappears when it can.
