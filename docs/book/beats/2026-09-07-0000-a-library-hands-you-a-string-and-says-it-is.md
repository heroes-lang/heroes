2026-09-07 | M-declared-freer | A library hands you a string and says it is yours now, which sounds generous until you notice you can either read it or give it back, never both: the moment the language let you free it, it stopped letting you look at it. So programs did the only thing left and quietly kept the string forever, forty bytes at a time, on a machine that could not see them doing it. Now the declaration says which C function owns the ending, and the compiler does the reading and the giving back in that order, without being asked twice.
