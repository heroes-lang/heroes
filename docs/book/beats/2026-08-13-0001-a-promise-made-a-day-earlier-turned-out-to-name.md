2026-08-13 | M-program-corpus | A promise made a day earlier turned out to name a shape the language could not spell. A review had asked that programs stop writing error names as bare text and give them proper names instead, and it wrote out what that would look like — one program's name for an error, borrowed by another. When the corpus finally needed exactly that, it did not compile: borrowing a *function* from another file worked, borrowing a *type* worked, borrowing a **value** did not, and had never worked since the day files could refer to one another. Nobody had noticed, because nobody had written the program that needed it. Then the change was made and measured, and the measurement went the way the review had warned in advance that it might: the tool that hunts for this class of mistake did not start catching more of them, it stopped finding any to hunt. Eighty-five places moved out of an instrument that catches nothing into one that catches everything. The mistake did not become detectable — it became a different mistake, one the compiler already refused.
