2026-08-13 | M-program-corpus | The tool that tidies a program's layout had been changing what programs mean. Given a division wrapped in brackets, followed by a request to turn the result into text, it removed the brackets — which moves the request onto the number underneath and produces something that is not the same program and does not even make sense. The reason is a number that was right when it was written: the tool ranks operators by how tightly they bind, and "tighter than everything" was written down as a specific rank rather than as a name. Later, six more operators were added below the middle of that scale, every rank above them moved up, and the five places that had spelled out the old number stayed where they were. It could not have been caught by the examples the project keeps for reading, because those are checked to already be in tidy form — a shape the tool would mangle had therefore never been written into one. It was caught by the first program in the whole repository that happened to divide a number and then ask for it as text.
