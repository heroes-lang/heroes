**This file is the record.** Every item ever ticked stays here, and every commit
subject in this repository cites this path (CLAUDE.md §14 does not rewrite a
record, it appends to it).

file held 192 of them across three kinds, and a list you have to filter before
you can read it is a list nobody opens:

| list | asks | read by | blocks anything? |

| [`DECIDE.md`](DECIDE.md) | **what should be true** — `Decide:`, an open question, a panel default awaiting a verdict | `/decide` | yes: the compiler behaves some way by default while it waits |

made this file, so a misfiling is visible rather than silent.
