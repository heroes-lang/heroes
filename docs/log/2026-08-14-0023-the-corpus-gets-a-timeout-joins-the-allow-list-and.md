A hang on an unattended harness burns the whole job where a failure costs one case, and the message it panics with names the likely cause — a C library waiting on a window, a display or a dialog the machine cannot show. **And the allow-list was asked the same question twice in one hour.** Its property test is *does this word name a file, load anything, or write anything* — `SDL2main` does none of the three and replaces the program's entry point; `-Wl,-rpath,<dir>` does none of the three and changes what the loader picks. Both act at **run** time, and the test is about **build** time. The rpath is allowed in that exact form because SDL3's own `.pc` needs it, with its escalation written in the code rather than waved past: a hostile `.pc` saying `-L/tmp/x -lfoo` already chooses the library, so this is not a new capability — but it lets the choice be swapped **after** the build by anyone who can write to that directory.
