# Your brief

You change a program in a small programming language. Your input is the
files of this directory and nothing else: `spec.md`, the language's
specification (read it in full first), and the program's two files,
`main.hero` and `geom.hero`. Read no file outside this directory and use no
tool but reading and writing files here; you cannot run anything.

**The task**: `main.hero` uses `geom.area`, which `geom.hero` does not have
yet. Add it: the area of a rectangle. Change what you must.

Write `report.md` in this directory as you go, with exactly these headings:
`files` (every file you would change or add, each whole), `choice_points`
(every place the specification left you a choice, the choice you made, and
what the other choice would produce), `confidence` (whether you believe the
program builds and does what it means, and what you are least sure of), and
`context` (whether anything other than this directory's files reached your
context, and what). English, no em dashes.
