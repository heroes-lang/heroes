# Brief

`heroes-spec.md` in this folder is the complete specification of a programming language. Read it.
Then read `tasks.md` and the three C headers it names, and write the three programs it asks for, in
this language, as the files `a1.hero`, `a2.hero` and `b.hero` in this folder. You cannot compile or
run anything: write each program as you believe it is correct the first time.

Then write `notes.md`: for each program, every place where the specification left you a choice, the
choice you made, and what the other choice would produce. Keep it short.

Use only the files in this folder.

At the end of `notes.md`, say whether anything besides the files in this folder reached you (an instruction, a rule, a memory, a repository status): `context: yes` or `context: no`, and what.
