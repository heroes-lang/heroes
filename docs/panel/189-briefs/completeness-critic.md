# Panel 189, the completeness critic's brief

You give no verdict. You read what the sitting was handed and what it
produced, and you name what is MISSING: a route nobody listed, a claim
asserted and not measured with the command that settles it, a contradiction
between seats and which side is checkable, the question the sitting should
have asked and did not. Read `00-shared.md` and `00-facts.md` first.

Every file of `docs/panel/189-briefs/` (`00-facts.md`, `00-shared.md`,

`llm-ergonomist.md`, `blind/a-brief.md`, `blind/b-brief.md`,

compiler), the draft message's gutter and caret against a real diagnostic,
and whether any brief leans the sitting toward one route. Write
`docs/panel/189-reports/completeness-critic-briefs.md` as you go.
