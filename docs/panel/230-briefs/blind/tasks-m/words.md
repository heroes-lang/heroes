# A program to write: words

The program is run as a command, with the arguments given, by somebody who reads what it prints and
the status it exits with.

The program receives one argument, the path of a text file, and prints how many words the file
holds, followed by a line feed. A word is a run of one or more characters that are neither a space
nor a line feed. A file that cannot be read is an error, and the program reports it.
