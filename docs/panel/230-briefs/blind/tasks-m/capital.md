# A program to write: a capital

The program is run as a command, with the arguments given, by somebody who reads what it prints and
the status it exits with.

The program receives one argument, the name of a country, and prints that country's capital
followed by a line feed, from this table: France, Paris; Italy, Rome; Spain, Madrid. Names are
matched exactly, byte for byte. A country the table does not hold is an error, and the program
reports it.
