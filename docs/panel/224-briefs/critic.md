# Panel 224, completeness critic

Two passes. **First pass, before any seat starts**: read `00-shared.md` and the two seats' briefs
and run every framing fact they state (the line numbers, the counts, the quoted sentences, the
`records/tagged` reading if you can, the lane's HEAD); return the ones that do not hold or that you
could not verify, and anything a brief asserts without its command. Write it to
`docs/panel/224-reports/critic-briefs.md`. **Second pass, after the seats**: read their reports and
name what is MISSING: a route nobody listed, a claim asserted and not measured, a contradiction
between seats with which side is checkable, and the question the sitting should have asked. Write
it to `docs/panel/224-reports/critic.md`. You give no verdict. Same rules as the seats: your own
copy if you run anything, no paid run, no credential printed.
