# What to do

`heroes-spec.md`, in this directory, is the specification of the programming
language Heroes: it is the whole language. Read it in full.

Then read `task.md`, the task. The package it uses is available: `use {PKG}`
binds `{BINDS}`.{RULE} No other description of it is
given. `previous.hero` is a program written for this
task; compiled as `main.hero` beside the package's modules, it did not
compile, and `diagnostics.txt` holds the compiler's messages. Write the
corrected program: one file, in Heroes as the specification defines it, that
compiles and prints exactly what the task asks.

Answer with these two sections and nothing else:

## program

The whole corrected program, as exactly one fenced code block marked `hero`.

## context

Whether anything besides the files of this directory reached you (a project,
rules, a memory, other files): `none` if nothing did, otherwise what.
