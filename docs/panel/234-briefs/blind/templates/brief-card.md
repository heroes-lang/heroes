# What to do

`heroes-spec.md`, in this directory, is the specification of the programming
language Heroes: it is the whole language. Read it in full.

Then read `task.md`, the task, and `card.md`, the interface card of the
package `{PKG}` that the task uses.{RULE} Write the program the task asks for: one
file, in Heroes as the specification defines it. It will be compiled as
`main.hero` in a directory that also holds the package's modules, so that
`use {PKG}` finds them. You cannot run a compiler: write the program you
expect to compile and to print exactly what the task asks, at the first try.

Answer with these two sections and nothing else:

## program

The whole program, as exactly one fenced code block marked `hero`.

## context

Whether anything besides the files of this directory reached you (a project,
rules, a memory, other files): `none` if nothing did, otherwise what.
