# What to do

`heroes-spec.md`, in this directory, is the specification of the programming
language Heroes: it is the whole language. Read it in full; its section 14
says how a program uses packages.

Then read `task.md`, the task, and every file it names. The folder `previous`
holds a program written for this task, `main.hero`, and the catalogue written
with it, where there was one. Built as `main.hero`, with that catalogue beside
it, in a directory that also holds the files `task.md` names, they were
refused, and `diagnostics.txt` holds the messages that refused them. Write the
corrected catalogue and program: the program one file in Heroes as the
specification defines it, both expected to build and to print exactly what
the task asks.

Answer with these three sections and nothing else:

## catalogue

The whole corrected catalogue, as exactly one fenced code block.

## program

The whole corrected program, as exactly one fenced code block marked `hero`.

## context

Whether anything besides the files of this directory reached you (a project,
rules, a memory, other files): `none` if nothing did, otherwise what.
