# What to do

`heroes-spec.md`, in this directory, is the specification of the programming
language Heroes: it is the whole language. Read it in full; its section 14
says how a program uses packages.

Then read `task.md`, the task, and every file it names. Write the program the
task asks for, one file in Heroes as the specification defines it, and the
program's catalogue, the file section 14 defines, for the packages the task
gives. The program will be compiled as `main.hero`, with the catalogue beside
it, in a directory that also holds the files `task.md` names, at their paths.
You cannot run a compiler or fetch a package: write the catalogue and the
program you expect to build and to print exactly what the task asks, at the
first try.

Answer with these three sections and nothing else:

## catalogue

The whole catalogue, as exactly one fenced code block.

## program

The whole program, as exactly one fenced code block marked `hero`.

## context

Whether anything besides the files of this directory reached you (a project,
rules, a memory, other files): `none` if nothing did, otherwise what.
