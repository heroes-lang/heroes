## E. The question the sitting should have asked

**Is this class about the argument or about the dereference?** Five routes legislate the argument at a Heroes call site; the class is a dereference, and it reaches three places an argument rule cannot: a `ptr` (exit 0, `8372224`, deterministic), a null behind a non-null handle (exit 133, silent — and this is defect 045's *original* reproducer shape, `ai_next: AI`, a list walk), and a field past the runtime's 4096-byte window (exit 139, silent, at `-O0`). Ask that question and the option set changes, which is CL-057's point about a recommendation being a claim about the set.

Three sub-questions nobody put: *which shape produced the `-O2` row, and is the class a wrong answer or an anonymous trap?*; *what does the toolchain we already ship do about it* — `--sanitize` names all four witnesses with file and line, so the default build is weaker than a leg the repository already owns; and *is the `-O0` half actually repaired?*

## F. Is the convergence the most robust and complete resolution

**No. It is the most complete answer available inside a frame that five seats did not leave.** Four seats converged on B (guard handles by default, `accepts_null` to opt out). Measured against the class rather than against the witness, B leaves open, at `-O2`, today:

- a null **`ptr`** argument: **exit 0, prints `8372224`** — and B cannot be widened to `ptr` without refusing `hints: nullptr` in a shipped golden;
- a null **behind** a non-null handle: **exit 133**, both streams empty;
- a field past 4096 bytes: **exit 139**, both streams empty, **at `-O0` as well**.

It pays for that subset with a fourth parameter word: +36 real spec tokens in the warden's best encoding, `selfhost/ast.hero` 4 lines from its DECIDED ceiling, the re-printing walk in `fmt`, `dump`, `mutate` and the syntax self-check, a new refusal in `check/marks.hero` that `.claude/rules/verification.md` sends to five golden suites, and a new meaning for the 35 unmarked handle parameters already in the tree. CLAUDE.md § Precedence asks for the most robust and production-ready resolution, never the compromise or the cheapest in tokens — and here the cheapest in tokens and the most complete are the **same** route, which is the tell that the frame, not the price, decided.

The robust and complete resolution is layered, and the sitting priced no layer but one:

1. **`-fno-delete-null-pointer-checks` in `selfhost/cli/flags.hero`** — closes the handle, nested and `ptr` wrong-answers at `-O2`; 0 surface, 0 spec tokens, `real` 2.87 s against 2.87 s on twenty compiler runs, 1.04 s against 1.04 s on 10^9 iterations, +0.38% seed size, 653 compiler tests green, emission byte-identical. It refuses **no** legal C, because it guards no argument.
2. **Widen `runtime/parts/stack.c:378`** from `addr < 4096` to the platform's own unmappable floor, asked of the value against a platform constant (`__PAGEZERO` is 4 GiB here; `mmap_min_addr` and 64 KiB are the other two, unrun from this Mac) — closes the exit-139 hole the brief believed closed.
3. **Handle `SIGTRAP`/`SIGILL`** beside `SIGSEGV` and `SIGBUS`, so a fold that traps says what happened instead of exiting 133 in silence. Measured catchable: signal 5, handler ran.
4. **Then, and only then, the boundary guard.** Route A's guard buys one thing the flag does not: the blame line. At `-O0` the panic says *called from `node_value`*; under the flag at `-O2` the same program says *called from main*, because inlining flattened the frame. That is a real diagnostic cost, and it is the honest argument for A — not the class, which A does not close.
5. **B's word last**, if a shipped program is ever refused. Exactly one witness exists today (the compiler-engineer's `freeaddrinfo` failure path), and its own report says two is a class and one is a witness.

Nobody priced the conjunction, and the conjunction is strictly more robust than any row of the table: layers 1 to 3 close every shape I could measure, refuse nothing that is legal C, and cost zero words a reader must learn.
