# Panel 204, ffi-pragmatist's brief

Read `00-shared.md` first. Your seat writes and runs the C: which real
libraries need another header first (as `jpeglib.h` needs `stdio.h`), which
define a macro a later header tests (as `cfgone`'s `LIMIT`), and which meant
to be configured that way (a `#define` before an `#include` as a library's
documented switch, `_GNU_SOURCE`, `NDEBUG`, `WIN32_LEAN_AND_MEAN`,
`STB_*_IMPLEMENTATION`); a census of order-dependence among the installed
headers on this Mac and in Docker `heroes-linux-arm64:latest`, starting from
panel 202's (read only); how a C programmer and a binding of the languages
you know states the order (a preamble, an include list). Say for each route
of `00-shared.md` which real binding it breaks and which it lets through
wrong.
