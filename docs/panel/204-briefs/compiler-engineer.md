and run them on `cfgone` (both orders), `jpeg` (both), `one`, and over the

another (what it compares, how many orders, what it refuses that is correct

refused order naming the group to move above (how the compiler can know
which header declares `FILE`, and whether one clang run says it); and what

before you report.
