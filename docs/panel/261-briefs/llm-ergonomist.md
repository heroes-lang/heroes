## What it measures, and why the sitting wants it

The proposal (`00-shared.md` § 1) lets a function type carry `@` and `lent`, so a table can bind a route, a command or
a transition to a function that changes the program's state in place. A reader who writes such a program from the
specification alone must **find the form, write the modes right at the type, at the function and at the call through
the value, and not be refused for a mode** (a read-only handler in a table of `@` handlers meets `never_rebound` under
today's rule, `00-shared.md` § 2 question 5); and under `now`, where no such form exists, the reader writes something
else: a chain of names (which the tasks forbid), the state passed and answered by value (the clerk's reference, which
builds), or **a change written into a copy that nothing hands back, which compiles and prints a wrong count**. That is
a sentence's effect on a reader, which the compiler-engineer and the ffi-pragmatist, who test truth, cannot measure.
The seat reads **only a copy of the specification** and the task (panel 175 item 7: never `design.md`, never the
repository).
