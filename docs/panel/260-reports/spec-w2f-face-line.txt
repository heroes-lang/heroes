# spec-w2f-face-line: the replacement text(s), each the whole of what it puts in place of its anchor

Anything beyond this document comes from packages or C libraries; processes and files from the language's `hero_os.h`, and sockets, clocks and the rest from its platform layer: `hero_net.h`, `hero_time.h` and every other `hero_` header it provides but the compiler's `hero_compiler.h`. A package holding a group whose header is one of these or includes one at any depth, or that binds a name one declares, must hold the line `layer` (section 4) in its module named as the package, `time.hero` beside `time/`, and a program holding one in the file you compile, and no other module may; a build links the layer only where a package or program it compiles holds it.
