# spec-w6-file-name: the replacement text(s), each the whole of what it puts in place of its anchor

Anything beyond this document comes from packages or C libraries; processes and files from the language's `hero_os.h`, and sockets, clocks and the rest from its platform layer: `hero_net.h`, `hero_time.h` and every other `hero_` header it provides but the compiler's `hero_compiler.h`. Only a module named `hero_<name>.hero` may hold a group whose header is one of these or includes one at any depth, or that binds a name one declares, and each so named must hold one; a build links the layer only where it compiles such a module.
