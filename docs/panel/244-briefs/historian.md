Read `00-shared.md` first. Web search and fetch are your instruments; every precedent `verified`
with its URL and the day read (2026-11-10), saying only what the page states. Questions: does Go's
language specification state the `internal` rule, or only the go command's documentation; where do
Cargo, Go, Dart, Swift and Zig state a dependency's source kinds (registry, git, local path) and
that a local path carries no checksum; where each states that fetched code lives (vendor, cache)
and that a build refuses a changed copy; which of those statements live in the language's
specification and which in the tool's manual.
