Code of C's own that switches onto a stack inside the thread's own calls `hero_stack_entered(low: ptr, bytes: i64) -> ()` (`hero_os.h`) before a callback runs there, and `hero_stack_left(low: ptr) -> ()` before that memory is used for anything else; a callback on such a stack C did not name aborts, saying the switch was not seen, if a function of the program then holds a value of more than 4,096 bytes.
