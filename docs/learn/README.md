# The learning list — what the author might want to understand

Read by **`/learn`**, and by nothing else. **Never convened by the assistant**:
not at a milestone close, not when this list grows, not as a suggestion at the
end of a step. It exists when the author asks for it.

Every question asks **what is true**: how a pass works, why a representation was
chosen, what a failure's cause was, what a golden guards against. None of them
blocks anything, which is why they stand apart from the work.

**A question is not an issue** (the author's *1a 2a* of 2026-10-05): it is a file
here and never in `issues/`, it carries no card, and it is never transcribed to
GitHub. From 2026-10-04 to 05 the questions were issues of the kind `learn`;
they came back keeping their names.

**One file per question**, `docs/learn/<year-month>/<day>/<stamp>-<slug>.md`, in
the folder of the day its name carries, the stamp the minute it was asked:
`- [ ] **<origin>** | <the question> | <where to look>` on its first line, and
an optional body indented four spaces opening with `**Origin:**` and its date.

**A question answered stays where it is, ticked**: this list is also its own
record. `records/lists` holds every file to this shape and counts the open ones.
